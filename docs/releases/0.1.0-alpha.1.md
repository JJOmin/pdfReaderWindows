## PDF Reader 0.1.0-alpha.1

First public alpha. A local PDF reader that reads German and English aloud and marks the spoken
sentence and word. Nothing leaves your PC.

### Install

1. Download `PDF-Reader-0.1.0-alpha.1-setup.exe` below and run it. Windows 10 or 11, 64-bit.
2. Windows SmartScreen will warn that the app is unrecognised, because the installer is not
   code-signed yet. Choose **More info**, then **Run anyway**.
3. Open a PDF with **Open**, press **Space** to read.

The speech models (about 700 MB) are inside the installer, so no second download is needed.

### What works

- Reading aloud with the sentence and the word highlighted, in the PDF view and in a restyled
  reading view (OpenDyslexic, Lexend and others).
- Highlights, underlines and comments; export to Markdown, or to a PDF copy that carries the marks.
- Search, zoom, remembered place per document.
- Voices: Kokoro (English), Piper Thorsten (German), Supertonic 3 (both). Each language can have a
  different voice for main text, quotes and headings.
- Optional: "Soften sentence edges" under Voices fades each sentence in and out.

### Known limits

- Alpha: expect rough edges. Please report them as GitHub issues, with the PDF page if you can
  share it. Text detection (headings, columns, headers) is the most likely source of wrong reads.
- Windows only. No auto-update.
- The larger XTTS-v2 GPU voice is not in the installer; it runs from a source checkout.
- You cannot add voice models to an installed copy yet.
